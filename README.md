Welcome to the **Gmail PDF Archiver** repository! This is a powerful, automated Chrome Extension designed to seamlessly export your Gmail conversations into high-quality PDFs, complete with all their associated attachments. Whether you're archiving important communications or just keeping backups, this extension simplifies the process right from your inbox.

✨ **Proudly AI-Crafted:** This entire project was fully vibecoded from the ground up using **Gemini 3.1 Pro on Antigravity**! It stands as a proud testament to the speed and power of modern AI-assisted software development. 🚀

## ✨ Features

- **One-Click Downloads**: Injects a convenient download button directly into your Gmail UI.
- **Silent PDF Generation**: Leverages the advanced Chrome Debugger API to generate pristine PDFs of email threads in the background without disrupting your workflow.
- **Smart Selection**: Intelligently captures emails based on inbox checkbox selections, or detects and downloads the active thread you're currently viewing.
- **Organized Exports**: Automatically saves your PDFs with structured, customizable naming conventions (e.g., `Gmail/{timestamp}/{subject}.pdf`), keeping your downloads impeccably organized.
- **Multi-Account Support**: Dynamically handles multiple Google accounts, ensuring downloads are routed correctly no matter which inbox you are logged into.
- **Live Progress Feedback**: Stay informed with unobtrusive, persistent toast notifications tracking the progress of your bulk downloads.
- **Attachment Extraction**: Safely captures and saves associated attachments alongside the thread.

## 🚀 Installation (Unpacked Extension)

Since this extension uses powerful APIs (like the Debugger API), you can install it locally in Developer Mode:

1. **Clone or Download** this repository.
2. Ensure you have Node.js installed, then install dependencies:
   ```bash
   npm install
   ```
3. Build the extension:
   ```bash
   npm run build
   ```
4. Open Google Chrome and navigate to `chrome://extensions/`.
5. Toggle **Developer mode** on in the top right corner.
6. Click **Load unpacked** and select the `dist` directory generated by the build step.

## 🔐 Permissions Required

To function correctly, the extension requests the following permissions:
- `downloads`: To save the generated PDFs and attachments to your local disk.
- `tabs`: To monitor the active Gmail tab and execute background processes safely.
- `debugger`: To utilize the Chrome DevTools Protocol for silent, accurate page-to-PDF rendering.
- `host_permissions`: Access is strictly limited to `https://mail.google.com/*` to respect your privacy and secure your data.
